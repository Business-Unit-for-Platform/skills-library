# Shared Skills Library

This repository contains reusable Agent skills and playbooks intended to work across business units.

## Skills

- [Interpersonal Communication Coach](skills/interpersonal-communication-coach/SKILL.md): prepare, improve, and rehearse respectful conversations.

## Adding a skill

- Put each skill in its own directory under `skills/`, with a `SKILL.md` containing a concise name, description, workflow, and boundaries.
- Keep instructions actionable and independent of a specific business unit unless the skill is intentionally scoped.
- Do not include private source notes, personal data, credentials, or unlicensed copied material.
- Distinguish evidence-backed guidance from heuristics; do not present uncertain claims as facts.
- Test the skill with realistic scenarios, including ambiguous goals and cases where the appropriate response is to ask for context or decline a tactic.
